This directory contains the active visual system for the site. Global theme styling is provided by `editorial.css`, homepage-specific layout by `homepage-editorial.css`, and reusable component styles by `components.css`. Legacy `theme.css`, `custom.css`, and `article-list.css` are intentionally not imported by `main.css` because they redefine global body, navigation, article, link, and color styles and conflict with the editorial system.
